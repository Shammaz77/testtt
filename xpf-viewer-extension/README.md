# Sheet XPF Viewer

This Chrome extension renders `.xpf` files made by the Sheet XPF Editor.

## Install locally

1. Open `chrome://extensions`.
2. Turn on **Developer mode**.
3. Click **Load unpacked**.
4. Select this folder: `xpf-viewer-extension`.
5. Open the extension details and enable **Allow access to file URLs**.

After that, opening a downloaded `.xpf` file in Chrome will show the sheet output instead of the raw source text.
